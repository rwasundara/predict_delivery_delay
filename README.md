# DataCo Smart Supply Chain – Setup Instructions

## 1. Download and Install Anaconda

Download and install Anaconda from the official website:

[Download Anaconda](https://www.anaconda.com/download)

## 2. Open Jupyter Notebook

1. Open **Anaconda Prompt**.
2. Type the following command:

   ```bash
   jupyter notebook
   ```
3. Press Enter to launch Jupyter Notebook in your web browser.

## 3. Upload Project Files

Upload the following two files into the same Jupyter Notebook working folder:

- `dataco_dual_prediction_pipeline_v3_final.ipynb`
- `DataCoSupplyChainDataset.csv`

## 4. Download the Dataset (If Not Available)

If you do not have the dataset, download it from Kaggle using the following link:

[Download DataCo Smart Supply Chain Dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis?select=DescriptionDataCo.csv)

After downloading, make sure `DataCoSupplyChainDataset.csv` is available in the same folder as the Jupyter Notebook.

## 5. Run the Notebook

Open `dataco_dual_prediction_pipeline_v3_final.ipynb` in Jupyter Notebook and run the notebook cells.
